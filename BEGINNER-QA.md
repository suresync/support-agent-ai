## Getting started

### What do I need to start tufting?
At minimum:
1. A **tufting gun** (cut pile, or cut + loop)
2. A **frame** to stretch your cloth
3. **Primary backing / tufting cloth**
4. **Yarn**
5. Finishing supplies: **latex glue**, **secondary backing**, and usually a **trimmer/carving clipper**

Starter kits cover gun + cloth + frame. Yarn and finishing packs are usually sold separately.

### I’m a complete beginner. Which starter kit should I buy?
A strong default is the **AK DUO Starter Kit – The Essential**. It includes:
- **AK DUO** gun (cut pile **and** loop pile)
- Polyester-cotton tufting cloth
- A sturdy frame (70×70 cm or 90×90 cm)

It’s beginner-friendly because of adjustable speed and the option to try both textures with one machine.

Other options:
- **Starter Kit – The Essential** — classic starter setup
- **AK-V Starter Kit – The Essential** — if you prefer that machine line

If you’ve only tufted once before, the **AK DUO** kit is still a good fit for learning.

### AK-I vs AK DUO — what’s the difference?
| Model | Pile types | Best for |
| --- | --- | --- |
| **AK-I** | Cut pile only | Beginners who only want cut-pile rugs |
| **AK DUO** | Cut **and** loop pile | Beginners who want to experiment with both textures |

Some shops call similar 2-in-1 guns “AK Pro”. At Tuftingshop we use **AK DUO** to make the dual function clear. It is a versatile starter machine, not our most advanced pro model.

### Which frame size should I choose?
- **70×70 cm** — smaller spaces, wall hangings, first projects  
- **90×90 cm** — more room for larger rug designs  

### Which cloth size should I choose?
Common options with kits and separately:
- **1×4 m** — long strip; watch width carefully when ordering  
- **2×2 m** — square-ish working area; popular for many first rugs  
- **4×4 m** — larger / multiple projects  

**Tip from support tickets:** double-check width vs length (e.g. 1×4 vs 2×2) before you buy. Cloth is **cut to order** and generally **cannot be returned**. If you ordered the wrong size, email us **before** it ships so we can swap it.

## Yarn, finishing & workflow

### Does a starter kit include yarn and glue?
Usually **no**. Kits focus on gun + cloth + frame. Add:
- Yarn cones in the colors you need  
- A **glue and backing pack** (or separate latex + secondary backing)  
- Trimming tools if you don’t have them yet  

### Cut pile vs loop pile — which should I start with?
- **Cut pile** — soft, carpet-like surface; most beginners start here  
- **Loop pile** — loops stay intact; different texture and look  

With an **AK DUO**, you can learn cut pile first, then try loop pile with the loop needle when you’re ready.

### How do I finish a rug?
Typical steps after tufting:
1. Apply latex glue on the back  
2. Add secondary backing fabric  
3. Trim / carve the front as needed  

See our Tufting Academy guides on the site for step-by-step help.
